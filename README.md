# ooobuv
# ОООбувь — система оформления заказов обуви 
Учебный проект: десктопное приложение для просмотра каталога обуви 
и оформления заказов. 
## Возможности - просмотр каталога моделей обуви с ценой, скидкой и наличием; - сортировка, фильтрация и поиск товаров; - оформление заказа авторизованным пользователем; - управление заказами (менеджер и администратор). 
## Требования - Python 3.10 - PostgreSQL 14 - библиотеки из файла requirements.txt 
## Установка и запуск 
1. Клонировать репозиторий: `git clone https://github.com/lhrmnttc/ooobuv` 
2. Создать окружение и установить зависимости: 
`python -m venv venv`, `venv\Scripts\activate`, `pip install -r requirements.txt` 
3. Создать базу данных и загрузить скрипт `import.sql`. 
4. Скопировать `config.ini.example` в `config.ini` и указать параметры подключения. 
5. Запустить приложение: `python main.py` 
## Структура репозитория - `main.py` — исходный код, содержащий все модули - `pics/` — изображения, логотип, иконка - `import.sql` — скрипт базы данных - `docs/er-diagram-ooobuv` - ER-диаграмма базы данных
## Описание ER-диаграммы
ER-диаграмма включает в себя следующие таблицы:
- `users` - Пользователи системы. Поля: ФИО, логин, пароль, роль в системе, - `orders` - Информация о заказах. Поля: номер заказа, состав заказа, дата доставки, ФИО клиента, код получения, статус, - `product` - Номер товара, наименование, цена, поставщик, продавец, категория, размер, скидка, описание, ссылка на изображение
