# ooobuv

# ОООбувь — система оформления заказов обуви

Учебный проект: десктопное приложение для просмотра каталога обуви и оформления заказов.

## Возможности

- просмотр каталога моделей обуви с ценой, скидкой и наличием;
- сортировка, фильтрация и поиск товаров;
- оформление заказа авторизованным пользователем;
- управление заказами (для менеджера и администратора).

## Требования

- Python 3.10
- PostgreSQL 18
- библиотеки из файла requirements.txt

## Установка и запуск

1. Клонировать репозиторий: `git clone https://github.com/lhrmnttc/ooobuv`
2. Создать окружение и установить зависимости:
   - `python -m venv venv`
   - `venv\Scripts\activate`
   - `pip install -r requirements.txt`
3. Создать базу данных и загрузить скрипт `import.sql`.
4. Скопировать `config.ini.example` в `config.ini` и указать параметры подключения.
5. Запустить приложение: `python main.py`

## Описание ER-диаграммы

ER-диаграмма включает в себя следующие таблицы:

- `users` — Пользователи системы. Поля: ФИО, логин, пароль, роль в системе.
- `orders` — Информация о заказах. Поля: номер заказа, состав заказа, дата доставки, ФИО клиента, код получения, статус.
- `product` — Номер товара, наименование, цена, поставщик, продавец, категория, размер, скидка, описание, ссылка на изображение.
- `pvz` — Информация о пунктах выдачи заказов: номер и адрес


## Запуск PostgreSQL через Docker Compose

### Требования

- Docker Desktop с поддержкой Linux-контейнеров
- Docker Compose v2
- Python 3.10
- PyQt6

### Запуск

1. Скопировать файл .env.example в .env и указать локальный пароль.
2. Собрать и запустить контейнеры:

   docker compose up --build -d

3. Импортировать базу данных:

   docker compose cp database/shoe_store.sql db:/tmp/shoe_store.sql

   docker compose exec db psql -v ON_ERROR_STOP=1 -U postgres -d ooobuv -f /tmp/shoe_store.sql

4. Проверить подключение:

   docker compose run --rm db-check

5. Настроить config.ini:
   - host: 127.0.0.1
   - port: 5433
   - name: ooobuv
   - user: postgres
   - password: локальный пароль из .env

6. Запустить приложение:

   python main.py

### Остановка контейнеров

docker compose stop

### Повторный запуск

docker compose start

Сервис db-check выполняет проверку подключения к PostgreSQL
и выводит количество таблиц в базе данных.
После успешного выполнения сервис завершает работу с кодом 0.

Файлы .env и config.ini не публикуются в репозитории.
